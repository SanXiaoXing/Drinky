# Drinky · 喝水提醒

项目是面向小米手环的 Vela JS 应用，使用原生 `.ux` 组件，设计宽度 192。

> **项目已归档，不再继续开发。** Drinky 的核心目标是在手环息屏或返回表盘后，仍能定时主动唤起喝水提醒。小米当前公开的 Vela JS 应用接口不支持第三方应用在后台定时启动并主动显示页面，因此无法实现这一核心功能。现有代码仅作为原型保留。

## 已实现

- 一键记录喝水，支持 150 / 250 / 350 / 500 ml，撤销上一杯。
- 每日进度及最近一次记录；按设备本地日期自动重置。
- 可选每日目标 1000–3000 ml（只是可调整的记录目标）。
- 提醒间隔 30 / 45 / 60 / 90 / 120 分钟，稍后 10 分钟提醒。
- 22:00–08:00 免打扰、提醒开关、振动测试。
- 本地保存；写入成功后才更新界面，失败可重试。

## 提醒边界

**手环端首页提醒仅在首页可见时运行。** Vela JS 普通应用切到后台后通常会停止运行。经查阅当前公开文档，尚未找到可供小米手环 9/10 上第三方 Vela JS 应用定时唤醒、推送通知或主动显示自身页面的接口。因此，息屏或返回表盘后的独立定时提醒仍未实现；不能把现有提醒开关当成后台提醒。

官方后台运行机制只面向正在进行的音频播放、上传下载和定位任务，后台运行还受审核约束；不能用这些无关任务维持喝水计时器。

## 开发与验证

```sh
npm install
npm test
npm run build
npm start
```

Node 测试建议使用 Node 20 或更新版本。构建器会在项目旁创建 `.temp_Drinky`，需具备父目录写入权限。

调试包：`dist/cn.sanxiaoxing.drinky.debug.1.0.0.rpk`。此包使用工具链的调试签名，不是商店发行包。

在 AIoT IDE 中选择手环模拟器并开始调试。重点检查：

1. 手环 9/10 窄屏下按钮、纵向滚动及设置文案是否完整。
2. 记录、撤销、退出重开后数据一致；跨日归零且保留设置。
3. 测试振动；到期只振动一次；稍后提醒、达标停止与夜间免打扰。

当前验证包含逻辑测试、页面存储/计时集成测试和 RPK 构建；不代表已完成模拟器视觉或真机验收。
